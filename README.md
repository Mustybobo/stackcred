# StackCred Contract

An on-chain credibility scoring contract that assigns and tracks
reputation points based on verified actions or contributions.

## Key Functions
- `assign-score` — Grant credibility points to a principal
- `reduce-score` — Decrease credibility score when necessary
- `get-score` — Retrieve a user's credibility score
- `set-weight` — Configure scoring weight for actions
- `get-score-history` — View score change records

Designed for DAO participation tracking, governance weighting,
contributor recognition, and trust-based protocol access.
